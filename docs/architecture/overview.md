│  └──────┬──────┘ └──────┬──────┘ └──────────┬──────────┘   │
└─────────┼───────────────┼───────────────────┼──────────────┘
          │               │                   │
    ┌─────▼─────┐   ┌────▼─────┐   ┌─────────▼─────────┐
    │ 11 模块    │   │ Oh My    │   │ safe_symlink()     │

    │            │   │ 输出函数  │   │ - 已存在跳过/备份   │

           │                        └────────────────────┘
    ┌──────┴──────────────────────────────────────────┐
    │                                                   │
    ▼                                                   ▼
┌──────────┐ ┌──────┐ ┌─────┐ ┌────────┐ ┌──────┐ ┌───────┐

│ install  │ │plat/ │ │ftpl/│ │lisp/   │ │plat/ │ │tools  │
└──────────┘ └──────┘ └─────┘ └────────┘ └──────┘ └───────┘
    │           │        │        │         │        │

## 质量保障体系

```
                    ┌─────────────────────┐
                    │   开发阶段           │
                    └──────────┬──────────┘
                               │
                    ┌──────────▼──────────┐
                    │  Git Hooks (本地)    │
                    │  pre-commit: 空格/CRLF│
                    │  commit-msg: 格式提示 │
                    │  pre-push: 分支保护   │
                    └──────────┬──────────┘
                               │
                    ┌──────────▼──────────┐
                    │  GitHub Actions (CI) │
                    │  ┌────────────────┐  │
                    │  │ ShellCheck     │  │
                    │  │ Syntax Check   │  │
                    │  │ Static Tests   │  │
                    │  │ Integration    │  │
                    │  └────────────────┘  │
                    └──────────┬──────────┘
                               │
                    ┌──────────▼──────────┐
                    │  验证脚本 (本地)      │
                    │  validate.sh         │
                    │  tests/test_install.sh     │
                    │  tests/test_integration.sh │
                    └─────────────────────┘
```
