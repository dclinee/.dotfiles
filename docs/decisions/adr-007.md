# ADR-007: 国内镜像源 + 代理回退策略

**状态**: 已接受
**日期**: 2025-03-01

## 背景

国内访问 GitHub、Homebrew 等资源缓慢，直接影响安装体验。

## 决策

- Homebrew: 使用 USTC 镜像
- Emacs 包: 使用清华镜像（gnu/nongnu/melpa）
- GitHub 资源: 使用 ghproxy.net/gh-proxy.com 代理回退
- 设置超时控制（--connect-timeout 30 --max-time 60）

## 后果

- 优点：国内安装速度快、有回退保障
- 缺点：镜像源可能不同步最新版本
